A faster drop-in replacement for csv-reader 1.0.0: for every input {text, header} it returns exactly the same {columns, rows, errors} value as csv-reader 1.0.0, at a fraction of the CPU time. Entry for the make.fun bounty "Read broken CSV files faster, 21 November 2026".

## Run it

```sh
node -e "import('./solve.js').then(m => console.log(JSON.stringify(m.run({text: 'a,b\n1,2', header: true}))))"
```

The harness driver main.ts reads /input/cases.json and writes /output/answers.json.
